THE DAILY BREW — WEBSITE PROJECT

1. Open this folder in Visual Studio Code.
2. Add the images from the Google Drive folder into the "images" folder.
3. Rename the supplied images to these filenames (or update the matching src paths in index.html):
   - hero.jpg          Main homepage/banner image
   - cappuccino.jpg    Cappuccino image
   - cold-coffee.jpg   Cold Coffee image
   - sandwich.jpg      Classic Sandwich image
   - brownie.jpg       Chocolate Brownie image
   - about.jpg         Café/interior/about image

IMPORTANT:
- Only use images from the provided Google Drive folder.
- If the Drive folder has fewer images, reuse one of those supplied images for more than one section.
- Do not download or add images from other websites.
- If the actual image files are PNG or WEBP, either rename them with the correct extension and update index.html, or convert them to JPG.

RUN THE WEBSITE:
- In VS Code, open index.html with the Live Server extension; or
- Open index.html directly in your browser.

The page uses plain HTML, CSS and JavaScript. No framework or package installation is required.
All required wording, menu items, prices and contact details are included as provided.
